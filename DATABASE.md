# OrangeHRM Database Configuration

## Overview

OrangeHRM uses **MySQL / MariaDB** as its database engine, accessed via
**Doctrine ORM** (`pdo_mysql` driver, `utf8mb4` charset).

The database connection is configured through the `Conf` class located at
`lib/confs/Conf.php`. This file is normally generated by the OrangeHRM
installer, but for local/dev usage it has been pre-configured to read values
from environment variables with sensible defaults.

---

## Configuration Flow

```
Environment variables (ORANGEHRM_DB_*)
       |
       v
lib/confs/Conf.php  <-- getenv() with fallback defaults
       |
       v
src/lib/config/Config.php  <-- Config::getConf() loads Conf.php
       |
       v
src/lib/orm/Doctrine.php   <-- reads Conf getters to build PDO connection
       |
       v
Doctrine EntityManager     <-- used by all DAOs, services, tests
```

---

## Environment Variables

| Variable                | Default      | Description                           |
|-------------------------|-------------|---------------------------------------|
| `ORANGEHRM_DB_HOST`     | `localhost` | MySQL server hostname                 |
| `ORANGEHRM_DB_PORT`     | `3306`      | MySQL server port                     |
| `ORANGEHRM_DB_NAME`     | `orangehrm` | Database name                         |
| `ORANGEHRM_DB_USER`     | `orangehrm` | Database username                     |
| `ORANGEHRM_DB_PASSWORD` | `orangehrm` | Database password                     |

> **Note:** When the PHP constant `ENVIRONMENT` equals `'test'` (set in
> `src/test/phpunit/Util/bootstrap.php`), the database name is automatically
> prefixed with `test_` (e.g. `test_orangehrm`). This isolates PHPUnit test
> data from the main application database.

## Local / Dev Setup

### 1. Start MySQL

```bash
sudo service mysql start
```

### 2. Create Databases and User

```sql
CREATE DATABASE IF NOT EXISTS orangehrm
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE DATABASE IF NOT EXISTS test_orangehrm
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE USER IF NOT EXISTS 'orangehrm'@'localhost'
  IDENTIFIED BY 'orangehrm';

GRANT ALL PRIVILEGES ON orangehrm.* TO 'orangehrm'@'localhost';
GRANT ALL PRIVILEGES ON test_orangehrm.* TO 'orangehrm'@'localhost';
FLUSH PRIVILEGES;
```

### 3. Verify Connectivity

```bash
mysql -u orangehrm -porangehrm -e "SHOW DATABASES;"
```

You should see both `orangehrm` and `test_orangehrm` listed.

### 4. (Optional) Override via Environment

If your MySQL instance uses different credentials, set the variables in your
shell or in `.env`:

```bash
export ORANGEHRM_DB_HOST=127.0.0.1
export ORANGEHRM_DB_PORT=3306
export ORANGEHRM_DB_NAME=my_ohrm_db
export ORANGEHRM_DB_USER=my_user
export ORANGEHRM_DB_PASSWORD=my_secret
```

## PHPUnit Tests

PHPUnit tests use the same `Conf.php` mechanism. The bootstrap file
(`src/test/phpunit/Util/bootstrap.php`) defines `ENVIRONMENT = 'test'`,
which causes `Conf` to prefix the database name with `test_`.

```bash
# Run all PHPUnit tests
./vendor/bin/phpunit

# Run a specific suite
./vendor/bin/phpunit --testsuite=Core
```

## Selenium-Cucumber Tests (Java / JDBC)

The Selenium-Cucumber test suite (`src/test/selenium-cucumber/`) connects
to the database independently using JDBC. Configuration is in
`src/test/selenium-cucumber/src/test/resources/config.properties`:

| Property       | Default Value                                                                                     |
|----------------|--------------------------------------------------------------------------------------------------|
| `db.url`       | `jdbc:mysql://localhost:3306/orangehrm?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC` |
| `db.username`  | `orangehrm`                                                                                      |
| `db.password`  | `orangehrm`                                                                                      |
| `db.driver`    | `com.mysql.cj.jdbc.Driver`                                                                       |

These can be overridden via:
- JVM system properties: `-Ddb.url=...`
- OS environment variables: `DB_URL=...`
- Environment-specific property files: `config-qa.properties`

### Running DB Validation Tests

```bash
cd src/test/selenium-cucumber
mvn test -Dtest=SequentialTestRunner -Dcucumber.filter.tags="@database"
```

## Troubleshooting

| Symptom | Cause | Fix |
|---------|-------|-----|
| `ConfigNotFoundException: not installed` | `lib/confs/Conf.php` missing | Ensure the file exists (check this repo) |
| `Can't connect to test database` | MySQL not running or wrong creds | Start MySQL, verify env vars |
| `Database is not configured - skipping` | Selenium `db.url` is empty | Set `db.url` in config.properties or env |
| `Access denied for user` | Wrong username/password | Verify MySQL user grants |
